# Brand logos

Drop official logo files here and the home page picks them up automatically
at build time (no code change needed). Use SVG where possible, and a mark
that works at about 18px tall. File names:

- `penn-state.svg` (or `.png`)
- `cornell.svg` (or `.png`)
- `brv.svg` (or `.png`) — Big Red Ventures
- `cupi.svg` (or `.png`) — Cornell University Physical Intelligence
- `tesla.svg` — already present (Simple Icons, CC0)

Until a file exists, the page shows a monogram placeholder in the theme color.
