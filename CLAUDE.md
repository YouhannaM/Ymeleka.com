## Development Commands

```bash
# Install dependencies
npm install

# Start development server with Turbopack (http://localhost:3000)
npm run dev

# Run linting
npm run lint

# Run type checking
npm run type-check

# Run tests
npm test

# Build for production
npm run build

# Build and export (for deployment)
npm run predeploy  # This runs 'npm run build' which includes static export

# Analyze bundle size
npm run analyze
```

## Architecture Overview

Youhanna Meleka's personal site: a Next.js static export (GitHub Pages) with two pages.

### Technology Stack
- **Next.js 16** with App Router and Turbopack, `output: 'export'`
- **TypeScript**, **React 19**
- **Biome** for code lint/format; **Prettier** for markdown and CSS
- **Jest** with React Testing Library and SWC
- **Node 20+**

### Pages
- `app/page.tsx`: the home page. Text only, centered: the headline, four short paragraphs with links (LinkedIn, Ficio with its apple mark, Penn State, the Jena-Xing Lab at Cornell, Big Red Ventures), the contact email, and the social links from `src/data/contact.ts`. Also emits the JSON-LD graph (Person, Organization Ficio, WebSite, ProfilePage).
- `app/gallery/page.tsx`: the gallery. Four pencil sketches (Cairo, Happy Valley, California, Ithaca) drawn at runtime by `public/places.js`, each on a ruled index card with no caption (the sketch keys are still cairo/stadium/factory/orchard). `places.js` is the sketch engine lifted from the earlier approved page script. The nav shows a Home link on this page. `app/places/page.tsx` is a meta-refresh redirect kept for old links.
- `src/components/WeaveFlow.tsx`: fixed canvas behind the content. It derives an edge field from `weave-light.webp`, seeds pixel grains on the woven outlines, and moves them along the weave only while the pointer is held down on the page (not on a link or button); near the cursor they glow as the hint. Pixel size, speed and density are constants at the top of the file; the tile width must match `background-size` in the CSS. Skipped under `prefers-reduced-motion`.
- `src/components/BrandMark.tsx`: small marks before the Penn State, Tesla, Cornell, CUPI and BRV links. Tesla is inlined in Tesla red; files in `public/logos/` (`penn-state.png`, `cornell.png`) are used when present, otherwise a monogram tile (Cornell red for BRV and CUPI). See `public/logos/README.md`.
- `app/layout.tsx`: metadata, Open Graph/Twitter cards (`/og.jpg`), favicons, Google Fonts link (Inter Tight, Inter), and the inline theme script.
- `src/components/SiteNav.tsx`: monogram home link, Places link, theme toggle. `src/components/ThemeToggle.tsx` is the client switch; `src/components/FicioMark.tsx` is the apple.

### Theme
- `app/globals.css` defines light and dark palettes with CSS variables. Dark follows `prefers-color-scheme` unless the visitor picked a theme; the choice is stored in `localStorage` under `theme` and applied to `<html data-theme>` before first paint by the inline script in the layout.
- Colors are black, white and grey; the only accent is Ficio orange (`#FF5A1F`), used for Ficio and for the dark-mode background outlines.
- Background: a woven coral pattern tiles behind every page. Light mode uses `public/weave-light.webp` (the white render), dark mode `public/weave-dark.webp` (its edges traced in orange on black). Both are seamless tiles generated by `scripts/weave-tiles.mjs` from the source strip; a translucent veil (`--veil`) and a radial halo behind `.home-text` (`--halo`) keep the copy readable.

### Search and AI readability
- `app/robots.ts` allows search and AI crawlers explicitly; `app/sitemap.ts` lists both pages; `public/llms.txt` is a plain-text summary for AI readers. Keep all three in step with the home page copy.

### Archived
- `src/site/` and `public/site.js` hold the earlier single-file homepage (hero, work stack, thesis, story, art, pitch form). Nothing serves them; they are kept for reference.
- `src/components/` also holds the original template's components with their tests; nothing depends on them.

### Deployment
- Static export to `/out`
- GitHub Actions deploys `main` to GitHub Pages; custom domain via `CNAME`
